# Introduction to Cyber Security

**Module:** [Introduction to Cyber Security](https://tryhackme.com/paths)
**Completed:** October 2026

## Room: [Offensive Security Intro](https://tryhackme.com/room/offensivesecurityintro)
Learned the basics of offensive security. I ran `dirb` against a fake bank site to brute-force directory paths and found a hidden `/bank-transfer` page. The site never checked if I was allowed to access it, so I was able to transfer money to myself.

## Room: [Defensive Security Intro](https://tryhackme.com/room/defensivesecurityintro)
Learned the basics of defensive security. The exercise put me in the role of an apprentice SOC analyst on my first solo shift. My dashboard flagged something suspicious and I had to investigate it before it became a bigger incident. I blocked the IP.
