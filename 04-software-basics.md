## What Tripped Me Up
I got tripped up learning binary for a moment because TryHackMe made it more complicated than it needed to be. All I have to do is look at what's on and what's off in the 1s and 0s, and the place value always doubles as you go left. So 4 bits like 0000 has place values of 8, 4, 2, 1, and that literally means the value is 0 because all the bits are off. It doesn't add up any of the 8, 4, 2, 1 because nothing is on. The number of bits is just how many digits are in the binary number. If it's 5 bits, the pattern extends to 16, 8, 4, 2, 1. Why the heck did TryHackMe have to make it so complicated when it's so simple.
